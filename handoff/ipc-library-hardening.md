## Fixed task-local choices

- Preserve the existing newline-delimited IPC record model; reject embedded newline data rather than silently splitting one write into multiple records.
- Restrict asynchronous operation PIDs to canonical positive decimal values before `wait` or `kill`.
- Restrict channel operands to the identity shape generated by `ipc_create` before channel filesystem operations.
- Document the caller obligation that `ipc_cancel` accepts only a PID returned for an asynchronous child operation started by the current shell.
- Document that `ipc_destroy` is only safe before either endpoint has begun `ipc_open`.
- Add the mandatory `res/sys/manual/ipc.lib.sh` topic and permanent IPC regression coverage.
