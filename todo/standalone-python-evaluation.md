# Standalone Python evaluation

## Intent

Try and compare the following standalone Python projects as candidate approaches potentially useful to RumiAI, without presupposing adoption:

- https://github.com/scc-tw/standalone-python
- https://github.com/astral-sh/python-build-standalone

## Why pending

Both projects have been explicitly identified for evaluation, but the evaluation is intentionally deferred from the current work unit.

## Scope

- `rumiai-dev`: evaluate the projects against current RumiAI development, portability and ownership constraints and record any accepted durable outcome in the appropriate canonical source.
- `rumiai-dev-PoCs`: host experimental validation if hands-on testing is needed.
- `rumiai-os` / `pkg-catalog`: change only if a later activated evaluation establishes a concrete adopted use.

- https://github.com/scc-tw/standalone-python
